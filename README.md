
# Voidex Store Official

Welcome to **Voidex Store Official**!

A Discord bot project built with Node.js and Discord.js.

## Features

- Moderation Commands
- Administration Tools
- Utility Commands
- Music Commands
- Fun Commands
- Game Commands
- Giveaway System
- Role Management
- Server Configuration

## Requirements

- Node.js 18 or newer
- npm
- Discord Bot Token
- Discord Application

## Installation

1. Download the project.
2. Open the project folder.
3. Install dependencies:

```bash
npm install
```

4. Configure your bot token and settings.
5. Start the bot:

```bash
npm start
```
